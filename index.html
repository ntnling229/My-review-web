Ch 1 Business Logic & Critical Thinking (商業邏輯與批判性思考)

1. Reasons to Learn Logic

  • Build Critical Thinking Skills:
    Study Validity (有效性) of arguments, Syllogisms (三段論), and recognize logical Fallacies (謬誤) to avoid misleading arguments.

    【中文補充】學習邏輯的核心目的是為了辨識論點結構，評估前提是否支持結論，避免陷入常見的邏輯陷阱。

  • Build Character & Credibility:
    Evaluate Evidence (證據), verify if information sources are Credible (可信), and enhance problem-solving confidence in business decision-making.

    【中文補充】有助於建立嚴謹客觀的個人品格與商業公信力。

2. 5 Core Critical Thinking Cognitive Skills

1. Observation (觀察能力) Identify problem areas and predict potential solution paths.
2. Analysis (分析能力) Gather data effectively, evaluate, and categorize logically.
3. Inference (推論能力) Draw valid conclusions based on objective data and facts.
4. Communication (溝通能力) Express reasoning clearly and absorb insights effectively.
5. Problem Solving (問題解決) Integrate cognitive insights to implement actionable business solutions.

Logic vs. Reasoning

Logic: A branch of philosophy studying principles of valid Deduction (演繹).

Reasoning: The thinking process of Derivation (推導) from premises to conclusions.

Reasoning Techniques

Substitution (替代法): Replacing equivalent variables ($A=B, C=A \implies C=B$).

Derivation (直接推導): Deducing facts step-by-step from given conditions.

Computers as Logic Machines

Computers are regarded as logic machines. They are made up of Logic Circuits, which are built from Logic Gates (AND, OR, NOT).

Ch 2 Methods of Elimination: Truth Table & Matrix Method (排除法)

What is Logic Puzzle? (什麼是邏輯拼圖)

Core Definition & Methodology

Logic Puzzle Definition (定義)

A particular type of puzzle that can be solved by logical reasoning.

（中文補充：一種可以透過邏輯推理來解決的特定拼圖。）

Core Principle (核心原則)

To solve the logic puzzles, one only needs to reason with the necessary information given.

（中文補充：解題核心是只需要運用所給出的必要資訊進行邏輯思考，即可得出答案。）

• Methodology: Think logically, then one can get the answer(s) using only the information given.

• Two methods (but, of course, not only two methods) to solve logic puzzles:

1. Method of elimination uses truth tables
（排除法使用真值表）
2. Method of elimination uses matrices
（排除法使用矩陣）

1. Truth Table Method (真值表法)

Best for binary variables (True/False, Yes/No)
  1. Step 1 (List All Possibilities): Total row possibilities = $2^n$ where $n$ is the number of binary variables.
  2. Step 2 (Eliminate Contradictions): Cross out rows that violate the given clues/premises.
  3. Step 3 (Determine Solution): The remaining valid row(s) represent the correct solution.

Classic Puzzle Models: Snoring puzzle (Alan, Bob, Calvin), product selection, blood donation combinations ($2^4 = 16$).

2. Matrix Method (矩陣法)

Best for multiple variables and multiple matching categories
  • Definition: A two-dimensional table used to cross-reference attributes across categories.
  • Multi-Variable Strategy: Construct interconnected 2D grids (e.g., Names vs. Jobs, Names vs. Dress Colors).

Classic Puzzle Models: Mislabeled candy jars (draw only 1 candy to solve), Dance partners puzzle (Dress colors vs. Boy names).

Categorical Logic & Square of Opposition (類別邏輯與對立方陣)

Class Logic I: Foundations, Statement Structures & Venn Diagrams

1. The Logic of Classes: 類別間的 4 種基本關係 (Slide 2)

① 完全包含 (Wholly includes)

一類別完全包含於另一類別中。

e.g., All cars are machines / All birds are animals

② 完全排除 (Wholly excludes)

一類別完全自另一類別中排除。

e.g., No men are women / No black are white

③ 部分包含 (Partly includes)

一類別至少部分包含於另一類別中。

e.g., Some odd numbers include prime numbers / Some animals are mammals

④ 部分排除 (Partly excludes)

一類別至少部分自另一類別中排除。

e.g., Some GEST1006 students are not from FBA / Some American people are not black

2. Statement Structure: 陳述的結構、質性與量詞 (Slide 3-7)

  • 基本組成 (Basic Parts): 包含主詞 Subject (S)（我們談論的事物）與謂詞 Predicate (P)（針對主詞所作的陳述）。
  • 質性 (Quality): 分為肯定 (Affirmative) 與否定 (Negative)。
    •
    Affirmative: The Moon rotates around the Earth （肯定陳述）
    •
    Negative: The Sun does not rotate around the Earth （否定陳述）
  • 量的範疇 (Quantity):
    Complete Affirmation (完全肯定): All students are intelligent.
    Partial Affirmation (部分肯定): Some mathematicians are women.
    Complete Negation (完全否定): No boys are girls.
    Partial Negation (部分否定): Some students are not hard working.

Square of Opposition (對立方陣圖解與六大邏輯關係)

1. Contradiction (矛盾關係)

[A vs O] & [E vs I]

Cannot be both true and cannot be both false (必為一真一假).

2. Contrariety (對立關係)

[A vs E]

Cannot be both true, but CAN be both false (不能同真，但可同假).

3. Sub-contrariety (分對立)

[I vs O]

CAN be both true, but cannot be both false (可同真，但不能同假).

4. Implication (牽連 / 暗示)

[A $\rightarrow$ I] & [E $\rightarrow$ O]

1. Universal is True $\implies$ Particular is True.

[I $\rightarrow$ A] & [O $\rightarrow$ E]

2. Particular is False $\implies$ Universal is False.

5. Equivalence (等價) & 6. Indifference (無關)

Equivalence: Statements always have identical truth values.
Indifference: Truth value of one statement has no effect on the other.

If two or more people are involved, then Betty is one of them.
