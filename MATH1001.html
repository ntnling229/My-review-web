4.1.1 Vector Spaces & The Ten Axioms (向量空間與十大公理，Pages 1 - 3)

DEFINITION (向量空間定義，Page 1)

A vector space (向量空間) is a nonempty set (非空集合) $V$ of objects, called vectors (向量), on which are defined two operations, called addition (加法) and multiplication by scalars (純量乘法) (real numbers，實數), subject to the ten axioms (or rules) (十條公理／規則) listed below. The axioms must hold for all vectors $\mathbf{u}$, $\mathbf{v}$, and $\mathbf{w}$ in $V$ and for all scalars (純量) $c$ and $d$.

1. Addition Closure (加法封閉性)

The sum of $\mathbf{u}$ and $\mathbf{v}$, denoted by $\mathbf{u} + \mathbf{v}$, is in $V$.

2. Commutative Law (加法交換律)

$\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$.

3. Associative Law (加法結合律)

$(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$.

4. Zero Vector (零向量)

There is a zero vector (零向量) $\mathbf{0}$ in $V$ such that $\mathbf{u} + \mathbf{0} = \mathbf{u}$.

5. Negative of $\mathbf{u}$ ($\mathbf{u}$ 的負向量)

For each $\mathbf{u}$ in $V$, there is a vector $-\mathbf{u}$ in $V$ such that $\mathbf{u} + (-\mathbf{u}) = \mathbf{0}$.

6. Scalar Multiple Closure (純量倍數封閉性)

The scalar multiple (純量倍數) of $\mathbf{u}$ by $c$, denoted by $c\mathbf{u}$, is in $V$.

7. Distributive Law (分配律)

$c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$.

8. Distributive Law (分配律)

$(c + d)\mathbf{u} = c\mathbf{u} + d\mathbf{u}$.

9. Scalar Associative Law (純量結合律)

$c(d\mathbf{u}) = (cd)\mathbf{u}$.

10. Scalar Identity (純量單位律)

$1\mathbf{u} = \mathbf{u}$.

Using only these axioms, one can show that the zero vector (零向量) in Axiom 4 is unique (唯一的), and the vector $-\mathbf{u}$, called the negative of $\mathbf{u}$ ($\mathbf{u}$ 的負向量), in Axiom 5 is unique (唯一的) for each $\mathbf{u}$ in $V$. (See Exercises 25 and 26.) Proofs of the following simple facts are also outlined in the exercises:

For each $\mathbf{u}$ in $V$ and scalar $c$,

$0\mathbf{u} = \mathbf{0}$ (1)
$c\mathbf{0} = \mathbf{0}$ (2)
$-\mathbf{u} = (-1)\mathbf{u}$ (3)
• Uniqueness of Zero Vector (零向量唯一性)：

Suppose $\mathbf{0}_1$ and $\mathbf{0}_2$ are both zero vectors in $V$. By Axiom 4, $\mathbf{0}_1 + \mathbf{0}_2 = \mathbf{0}_1$ and $\mathbf{0}_2 + \mathbf{0}_1 = \mathbf{0}_2$. By Axiom 2, $\mathbf{0}_1 = \mathbf{0}_1 + \mathbf{0}_2 = \mathbf{0}_2 + \mathbf{0}_1 = \mathbf{0}_2$.

• Uniqueness of Negative Vector (負向量唯一性)：

Suppose $\mathbf{v}_1$ and $\mathbf{v}_2$ both satisfy $\mathbf{u} + \mathbf{v}_1 = \mathbf{0}$ and $\mathbf{u} + \mathbf{v}_2 = \mathbf{0}$. Then:

$\mathbf{v}_1 = \mathbf{v}_1 + \mathbf{0} = \mathbf{v}_1 + (\mathbf{u} + \mathbf{v}_2) = (\mathbf{v}_1 + \mathbf{u}) + \mathbf{v}_2 = (\mathbf{u} + \mathbf{v}_1) + \mathbf{v}_2 = \mathbf{0} + \mathbf{v}_2 = \mathbf{v}_2 + \mathbf{0} = \mathbf{v}_2$.

• Proof of (1) $0\mathbf{u} = \mathbf{0}$：

$0\mathbf{u} = (0 + 0)\mathbf{u} = 0\mathbf{u} + 0\mathbf{u}$ (Axiom 8). Adding $-(0\mathbf{u})$ to both sides: $0\mathbf{u} + (-(0\mathbf{u})) = (0\mathbf{u} + 0\mathbf{u}) + (-(0\mathbf{u})) \implies \mathbf{0} = 0\mathbf{u} + (0\mathbf{u} + (-(0\mathbf{u}))) = 0\mathbf{u} + \mathbf{0} = 0\mathbf{u}$.

• Proof of (2) $c\mathbf{0} = \mathbf{0}$：

$c\mathbf{0} = c(\mathbf{0} + \mathbf{0}) = c\mathbf{0} + c\mathbf{0}$ (Axiom 7). Adding $-(c\mathbf{0})$ to both sides gives $\mathbf{0} = c\mathbf{0}$.

• Proof of (3) $-\mathbf{u} = (-1)\mathbf{u}$：

$\mathbf{u} + (-1)\mathbf{u} = 1\mathbf{u} + (-1)\mathbf{u} = (1 + (-1))\mathbf{u} = 0\mathbf{u} = \mathbf{0}$ (Axioms 10, 8, and Eq. 1). By uniqueness of the negative of $\mathbf{u}$, $(-1)\mathbf{u} = -\mathbf{u}$.

The spaces $\mathbb{R}^n$, where $n \ge 1$, are the premier examples (最主要的範例) of vector spaces. The geometric intuition (幾何直覺) developed for $\mathbb{R}^3$ will help you understand and visualize many concepts throughout the chapter.

Let $V$ be the set of all arrows (directed line segments，有向線段／箭頭) in three-dimensional space, with two arrows regarded as equal if they have the same length and point in the same direction. Define addition by the parallelogram rule (平行四邊形法則) (from Section 1.3), and for each $\mathbf{v}$ in $V$, define $c\mathbf{v}$ to be the arrow whose length is $|c|$ times the length of $\mathbf{v}$, pointing in the same direction as $\mathbf{v}$ if $c \ge 0$ and otherwise pointing in the opposite direction. (See Figure 1.) Show that $V$ is a vector space. This space is a common model in physical problems for various forces.

SOLUTION: The definition of $V$ is geometric, using concepts of length and direction. No $xyz$-coordinate system is involved. An arrow of zero length is a single point and represents the zero vector (零向量). The negative of $\mathbf{v}$ is $(-1)\mathbf{v}$. So Axioms 1, 4, 5, 6, and 10 are evident. The rest are verified by geometry. For instance, see Figures 2 and 3.

Let $S$ be the space of all doubly infinite sequences (雙向無窮數列) of numbers (usually written in a row rather than a column):

$\{y_k\} = (\dots, y_{-2}, y_{-1}, y_0, y_1, y_2, \dots)$

If $\{z_k\}$ is another element of $S$, then the sum $\{y_k\} + \{z_k\}$ is the sequence $\{y_k + z_k\}$ formed by adding corresponding terms of $\{y_k\}$ and $\{z_k\}$. The scalar multiple $c\{y_k\}$ is the sequence $\{c\, y_k\}$. The vector space axioms are verified in the same way as for $\mathbb{R}^n$.

Elements of $S$ arise in engineering, for example, whenever a signal is measured (or sampled，取樣) at discrete times. A signal might be electrical, mechanical, optical, and so on. The major control systems for the space shuttle use discrete (or digital) signals (離散／數位信號). For convenience, we will call $S$ the space of (discrete-time) signals (離散時間信號空間). A signal may be visualized by a graph as in Figure 4.

FIGURE 4 (Page 8): A Discrete-Time Signal

For $n \ge 0$, the set $\mathbb{P}_n$ of polynomials of degree at most $n$ (次數不超過 $n$ 的多項式集合) consists of all polynomials of the form

$p(t) = a_0 + a_1 t + a_2 t^2 + \dots + a_n t^n$ (4)

where the coefficients (係數) $a_0, \dots, a_n$ and the variable $t$ are real numbers. The degree (次數) of $p$ is the highest power of $t$ in (4) whose coefficient is not zero. If $p(t) = a_0 \ne 0$, the degree of $p$ is zero. If all the coefficients are zero, $p$ is called the zero polynomial (零多項式). The zero polynomial is included in $\mathbb{P}_n$ even though its degree, for technical reasons, is not defined.

If $p$ is given by (4) and if $q(t) = b_0 + b_1 t + \dots + b_n t^n$, then the sum $p + q$ is defined by

$(p + q)(t) = p(t) + q(t) = (a_0 + b_0) + (a_1 + b_1)t + \dots + (a_n + b_n)t^n$

$(cp)(t) = c\,p(t) = ca_0 + (ca_1)t + \dots + (ca_n)t^n$

These definitions satisfy Axioms 1 and 6 because $p + q$ and $cp$ are polynomials of degree less than or equal to $n$. Axioms 2, 3, and 7–10 follow from properties of the real numbers. Clearly, the zero polynomial acts as the zero vector in Axiom 4. Finally, $(-1)p$ acts as the negative of $p$, so Axiom 5 is satisfied. Thus $\mathbb{P}_n$ is a vector space.

Let $V$ be the set of all real-valued functions (實值函數) defined on a set $\mathbb{D}$. (Typically, $\mathbb{D}$ is the set of real numbers or some interval on the real line.) Functions are added in the usual way: $f + g$ is the function whose value at $t$ in the domain (定義域) $\mathbb{D}$ is $f(t) + g(t)$. Likewise, for a scalar $c$ and an $f$ in $V$, the scalar multiple $cf$ is the function whose value at $t$ is $cf(t)$. For instance, if $\mathbb{D} = \mathbb{R}$, $f(t) = 1 + \sin 2t$, and $g(t) = 2 + .5t$, then

$(f + g)(t) = 3 + \sin 2t + .5t \quad \text{and} \quad (2g)(t) = 4 + t$

Two functions in $V$ are equal if and only if their values are equal for every $t$ in $\mathbb{D}$. Hence the zero vector in $V$ is the function that is identically zero (恆為零的函數), $f(t) = 0$ for all $t$, and the negative of $f$ is $(-1)f$. Axioms 1 and 6 are obviously true, and the other axioms follow from properties of the real numbers, so $V$ is a vector space.

It is important to think of each function in the vector space $V$ of Example 5 as a single object (單一物件), as just one "point" or vector in the vector space. The sum of two vectors $f$ and $g$ (functions in $V$, or elements of any vector space) can be visualized as in Figure 5, because this can help you carry over to a general vector space the geometric intuition you have developed while working with the vector space $\mathbb{R}^n$. See the Study Guide for help as you learn to adopt this more general point of view.

4.1.2 Subspaces (子空間，Pages 14 - 20)

In many problems, a vector space consists of an appropriate subset of vectors from some larger vector space. In this case, only three of the ten vector space axioms (十條向量空間公理中的三條) need to be checked; the rest are automatically satisfied.

DEFINITION (子空間定義，Page 14)

A subspace (子空間) of a vector space $V$ is a subset $H$ of $V$ that has three properties (三個性質):

a. The zero vector (零向量) of $V$ is in $H$.

b. $H$ is closed under vector addition (對向量加法封閉). That is, for each $\mathbf{u}$ and $\mathbf{v}$ in $H$, the sum $\mathbf{u} + \mathbf{v}$ is in $H$.

c. $H$ is closed under multiplication by scalars (對純量乘法封閉). That is, for each $\mathbf{u}$ in $H$ and each scalar $c$, the vector $c\mathbf{u}$ is in $H$.

Properties (a), (b), and (c) guarantee that a subspace $H$ of $V$ is itself a vector space, under the vector space operations already defined in $V$. To verify this, note that properties (a), (b), and (c) are Axioms 1, 4, and 6. Axioms 2, 3, and 7–10 are automatically true in $H$ because they apply to all elements of $V$, including those in $H$. Axiom 5 is also true in $H$, because if $\mathbf{u}$ is in $H$, then $(-1)\mathbf{u}$ is in $H$ by property (c), and we know from equation (3) earlier in this section that $(-1)\mathbf{u}$ is the vector $-\mathbf{u}$ in Axiom 5.

So every subspace is a vector space. Conversely, every vector space is a subspace (of itself and possibly of other larger spaces). The term subspace (子空間) is used when at least two vector spaces are in mind, with one inside the other, and the phrase subspace of $V$ ($V$ 的子空間) identifies $V$ as the larger space. (See Figure 6.)

FIGURE 6 (Page 16): A Subspace of $V$

EXAMPLE 6: The set consisting of only the zero vector in a vector space $V$ is a subspace of $V$, called the zero subspace (零子空間) and written as $\{\mathbf{0}\}$.

EXAMPLE 7: Let $\mathbb{P}$ be the set of all polynomials with real coefficients (所有實係數多項式集合), with operations in $\mathbb{P}$ defined as for functions. Then $\mathbb{P}$ is a subspace of the space of all real-valued functions defined on $\mathbb{R}$. Also, for each $n \ge 0$, $\mathbb{P}_n$ is a subspace of $\mathbb{P}$, because $\mathbb{P}_n$ is a subset of $\mathbb{P}$ that contains the zero polynomial, the sum of two polynomials in $\mathbb{P}_n$ is also in $\mathbb{P}_n$, and a scalar multiple of a polynomial in $\mathbb{P}_n$ is also in $\mathbb{P}_n$.

EXAMPLE 8: The vector space $\mathbb{R}^2$ is not a subspace of $\mathbb{R}^3$ because $\mathbb{R}^2$ is not even a subset of $\mathbb{R}^3$. (The vectors in $\mathbb{R}^3$ all have three entries, whereas the vectors in $\mathbb{R}^2$ have only two.) The set

$H = \left\{ \begin{bmatrix} s \\ t \\ 0 \end{bmatrix} : s \text{ and } t \text{ are real} \right\}$

is a subset of $\mathbb{R}^3$ that "looks" and "acts like" $\mathbb{R}^2$, although it is logically distinct from $\mathbb{R}^2$. See Figure 7. Show that $H$ is a subspace of $\mathbb{R}^3$.

SOLUTION: The zero vector is in $H$, and $H$ is closed under vector addition and scalar multiplication because these operations on vectors in $H$ always produce vectors whose third entries are zero (and so belong to $H$). Thus $H$ is a subspace of $\mathbb{R}^3$.

EXAMPLE 9: A plane in $\mathbb{R}^3$ not through the origin (不過原點) is not a subspace of $\mathbb{R}^3$, because the plane does not contain the zero vector of $\mathbb{R}^3$. Similarly, a line in $\mathbb{R}^2$ not through the origin, such as in Figure 8, is not a subspace of $\mathbb{R}^2$.

4.1.3 A Subspace Spanned by a Set (由集合張成的子空間，Pages 21 - 28)

The next example illustrates one of the most common ways of describing a subspace. As in Chapter 1, the term linear combination (線性組合) refers to any sum of scalar multiples of vectors, and $\text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ denotes the set of all vectors that can be written as linear combinations of $\mathbf{v}_1, \dots, \mathbf{v}_p$.

SOLUTION: The zero vector is in $H$, since $\mathbf{0} = 0\mathbf{v}_1 + 0\mathbf{v}_2$. To show that $H$ is closed under vector addition, take two arbitrary vectors in $H$, say,

$\mathbf{u} = s_1\mathbf{v}_1 + s_2\mathbf{v}_2$ and $\mathbf{w} = t_1\mathbf{v}_1 + t_2\mathbf{v}_2$

By Axioms 2, 3, and 8 for the vector space $V$,

$\mathbf{u} + \mathbf{w} = (s_1\mathbf{v}_1 + s_2\mathbf{v}_2) + (t_1\mathbf{v}_1 + t_2\mathbf{v}_2) = (s_1 + t_1)\mathbf{v}_1 + (s_2 + t_2)\mathbf{v}_2$

So $\mathbf{u} + \mathbf{w}$ is in $H$. Furthermore, if $c$ is any scalar, then by Axioms 7 and 9,

$c\mathbf{u} = c(s_1\mathbf{v}_1 + s_2\mathbf{v}_2) = (cs_1)\mathbf{v}_1 + (cs_2)\mathbf{v}_2$

which shows that $c\mathbf{u}$ is in $H$ and $H$ is closed under scalar multiplication. Thus $H$ is a subspace of $V$.

In Section 4.5, you will see that every nonzero subspace of $\mathbb{R}^3$, other than $\mathbb{R}^3$ itself, is either $\text{Span}\{\mathbf{v}_1, \mathbf{v}_2\}$ for some linearly independent (線性獨立) $\mathbf{v}_1$ and $\mathbf{v}_2$ or $\text{Span}\{\mathbf{v}\}$ for $\mathbf{v} \ne \mathbf{0}$. In the first case, the subspace is a plane through the origin (過原點的平面); in the second case, it is a line through the origin (過原點的直線). (See Figure 9.) It is helpful to keep these geometric pictures in mind, even for an abstract vector space.

FIGURE 9 (Page 23): An Example of a Subspace
THEOREM 1 (定理 1，Page 24)

If $\mathbf{v}_1, \dots, \mathbf{v}_p$ are in a vector space $V$, then $\text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ is a subspace (子空間) of $V$.

We call $\text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ the subspace spanned (or generated) by (由……張成／生成的子空間) $\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$. Given any subspace $H$ of $V$, a spanning (or generating) set (張成集／生成集) for $H$ is a set $\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ in $H$ such that $H = \text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$.

Let $H$ be the set of all vectors of the form $(a - 3b, b - a, a, b)$, where $a$ and $b$ are arbitrary scalars. That is, let $H = \{(a - 3b, b - a, a, b) : a \text{ and } b \text{ in } \mathbb{R}\}$. Show that $H$ is a subspace of $\mathbb{R}^4$.

SOLUTION: Write the vectors in $H$ as column vectors. Then an arbitrary vector in $H$ has the form

$$\begin{bmatrix} a - 3b \\ b - a \\ a \\ b \end{bmatrix} = a \begin{bmatrix} 1 \\ -1 \\ 1 \\ 0 \end{bmatrix} + b \begin{bmatrix} -3 \\ 1 \\ 0 \\ 1 \end{bmatrix}$$

This calculation shows that $H = \text{Span}\{\mathbf{v}_1, \mathbf{v}_2\}$ where $\mathbf{v}_1 = \begin{bmatrix} 1 \\ -1 \\ 1 \\ 0 \end{bmatrix}$ and $\mathbf{v}_2 = \begin{bmatrix} -3 \\ 1 \\ 0 \\ 1 \end{bmatrix}$. Thus $H$ is a subspace of $\mathbb{R}^4$ by Theorem 1.

Example 11 illustrates a useful technique of expressing a subspace $H$ as the set of linear combinations of some small collection of vectors. If $H = \text{Span}\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$, we can think of the vectors $\mathbf{v}_1, \dots, \mathbf{v}_p$ in the spanning set as handles (把手) that allow us to hold on to the subspace $H$. Calculations with the infinitely many vectors in $H$ are often reduced to operations with the finite number of vectors in the spanning set.

For what value(s) of $h$ will $\mathbf{y}$ be in the subspace of $\mathbb{R}^3$ spanned by $\mathbf{v}_1$, $\mathbf{v}_2$, $\mathbf{v}_3$, if

$$\mathbf{v}_1 = \begin{bmatrix} 1 \\ -1 \\ -2 \end{bmatrix}, \quad \mathbf{v}_2 = \begin{bmatrix} 5 \\ -4 \\ -7 \end{bmatrix}, \quad \mathbf{v}_3 = \begin{bmatrix} -3 \\ 1 \\ 0 \end{bmatrix}, \quad \text{and} \quad \mathbf{y} = \begin{bmatrix} -4 \\ 3 \\ h \end{bmatrix}$$

SOLUTION: This question is Practice Problem 2 in Section 1.3, written here with the term subspace rather than $\text{Span}\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\}$. The solution there shows that $\mathbf{y}$ is in $\text{Span}\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\}$ if and only if $h = 5$. That solution is worth reviewing now, along with Exercises 11–16 and 19–21 in Section 1.3.

完整推導步驟：

$\mathbf{y} \in \text{Span}\{\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3\}$ if and only if $x_1\mathbf{v}_1 + x_2\mathbf{v}_2 + x_3\mathbf{v}_3 = \mathbf{y}$ is consistent. Row-reduce the augmented matrix:

$$\begin{bmatrix} 1 & 5 & -3 & -4 \\ -1 & -4 & 1 & 3 \\ -2 & -7 & 0 & h \end{bmatrix} \xrightarrow{\substack{R_2 + R_1 \to R_2 \\ R_3 + 2R_1 \to R_3}} \begin{bmatrix} 1 & 5 & -3 & -4 \\ 0 & 1 & -2 & -1 \\ 0 & 3 & -6 & h - 8 \end{bmatrix} \xrightarrow{R_3 - 3R_2 \to R_3} \begin{bmatrix} 1 & 5 & -3 & -4 \\ 0 & 1 & -2 & -1 \\ 0 & 0 & 0 & h - 5 \end{bmatrix}$$

Consistency requires $h - 5 = 0$, so $h = 5$.

Although many vector spaces in this chapter will be subspaces of $\mathbb{R}^n$, it is important to keep in mind that the abstract theory (抽象理論) applies to other vector spaces as well. Vector spaces of functions (函數向量空間) arise in many applications, and they will receive more attention later.

Null Space $\text{Nul } A$ (零空間，Pages 2 - 12)

For an $m \times n$ matrix $A$, $\text{Nul } A = \{\mathbf{x} \in \mathbb{R}^n : A\mathbf{x} = \mathbf{0}\}$.

THEOREM 2: $\text{Nul } A$ is a subspace of $\mathbb{R}^n$ (homogeneous equations only; nonhomogeneous solution sets do not contain $\mathbf{0}$).

Explicit Spanning Set (Ex. 3): Row-reduce $[A\;\mathbf{0}]$ to RREF, express basic variables in terms of free variables, and decompose into linear combinations of vectors—one per free variable (automatically linearly independent when nonzero).

Column Space $\text{Col } A$ (行空間，Pages 13 - 17)

For $A = [\mathbf{a}_1 \;\; \dots \;\; \mathbf{a}_n]$ ($m \times n$), $\text{Col } A = \text{Span}\{\mathbf{a}_1, \dots, \mathbf{a}_n\} = \{\mathbf{b} : \mathbf{b} = A\mathbf{x} \text{ for some } \mathbf{x} \in \mathbb{R}^n\}$.

THEOREM 3: $\text{Col } A$ is a subspace of $\mathbb{R}^m$.

$\text{Col } A = \mathbb{R}^m$ iff $A\mathbf{x} = \mathbf{b}$ has a solution for each $\mathbf{b} \in \mathbb{R}^m$. (Ex. 4 writes $W$ as column vectors of $A$.)

Aspect $\text{Nul } A$ ($m \times n$ matrix $A$) $\text{Col } A$ ($m \times n$ matrix $A$)
Ambient Space Subspace of $\mathbb{R}^n$ Subspace of $\mathbb{R}^m$
Definition & Finding Vectors Implicitly defined ($A\mathbf{x} = \mathbf{0}$); requires row operations on $[A\;\mathbf{0}]$. Explicitly defined (linear combinations of columns of $A$); columns of $A$ are directly displayed.
Membership Test for $\mathbf{v}$ Easy: check if $A\mathbf{v} = \mathbf{0}$. Requires checking consistency of $A\mathbf{x} = \mathbf{v}$ (row operations).
Trivial / Full Space Equivalence $\text{Nul } A = \{\mathbf{0}\}$ $\iff$ trivial solution only $\iff$ $\mathbf{x} \mapsto A\mathbf{x}$ is one-to-one. $\text{Col } A = \mathbb{R}^m$ $\iff$ $A\mathbf{x} = \mathbf{b}$ consistent for all $\mathbf{b} \in \mathbb{R}^m$ $\iff$ $\mathbf{x} \mapsto A\mathbf{x}$ maps $\mathbb{R}^n$ onto $\mathbb{R}^m$.
Kernel and Range of a Linear Transformation (線性變換的核與值域，Pages 25 - 27)

A linear transformation $T: V \to W$ satisfies $T(\mathbf{u}+\mathbf{v}) = T(\mathbf{u})+T(\mathbf{v})$ and $T(c\mathbf{u}) = cT(\mathbf{u})$ for all $\mathbf{u}, \mathbf{v} \in V$ and scalars $c$.

The kernel (null space) of $T$ is $\{\mathbf{u} \in V : T(\mathbf{u}) = \mathbf{0}\}$ (a subspace of $V$); the range of $T$ is $\{T(\mathbf{x}) : \mathbf{x} \in V\}$ (a subspace of $W$). For $T(\mathbf{x}) = A\mathbf{x}$, kernel is $\text{Nul } A$ and range is $\text{Col } A$. (Ex. 8: differentiation $D(f) = f'$ from differentiable functions with continuous derivatives to $C[a,b]$ has kernel = constant functions and range = $C[a,b]$.)

§ 4.3 Linearly Independent Sets; Bases (線性獨立集；基底)

Pages 1 - 23

Linear Independence & Dependence (Pages 1 - 3): $\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ in $V$ is linearly independent if $c_1\mathbf{v}_1 + \dots + c_p\mathbf{v}_p = \mathbf{0}$ has only the trivial solution $c_1 = \dots = c_p = 0$; otherwise it is linearly dependent. Single vector $\{\mathbf{v}\}$ is independent iff $\mathbf{v} \ne \mathbf{0}$; two vectors are dependent iff one is a multiple of the other; any set containing $\mathbf{0}$ is dependent.

THEOREM 4 (Page 2): An indexed set $\{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ ($p \ge 2$) with $\mathbf{v}_1 \ne \mathbf{0}$ is linearly dependent iff some $\mathbf{v}_j$ ($j > 1$) is a linear combination of $\mathbf{v}_1, \dots, \mathbf{v}_{j-1}$. (Ex. 1: $\{1, t, 4-t\}$ dependent since $4-t = 4(1) - t$; Ex. 2: $\{\sin t, \cos t\}$ independent in $C[0,1]$, while $\{\sin t \cos t, \sin 2t\}$ dependent via $\sin 2t = 2\sin t \cos t$.)

Basis Definition & Key Theorems (基底定義與核心定理，Pages 4 - 23)

DEFINITION (Page 4): Let $H$ be a subspace of $V$. $\mathcal{B} = \{\mathbf{b}_1, \dots, \mathbf{b}_p\}$ in $V$ is a basis for $H$ if (i) $\mathcal{B}$ is linearly independent and (ii) $H = \text{Span}\{\mathbf{b}_1, \dots, \mathbf{b}_p\}$.

Standard Bases: Columns of invertible $n \times n$ matrix form a basis for $\mathbb{R}^n$ (Ex. 3, Ex. 5); $\{\mathbf{e}_1, \dots, \mathbf{e}_n\}$ is the standard basis for $\mathbb{R}^n$ (Ex. 4); $\{1, t, t^2, \dots, t^n\}$ is the standard basis for $\mathbb{P}_n$ (Ex. 6).

THEOREM 5 — Spanning Set Theorem (Page 12): For $S = \{\mathbf{v}_1, \dots, \mathbf{v}_p\}$ and $H = \text{Span } S$: (a) if $\mathbf{v}_k$ is a linear combination of remaining vectors in $S$, removing $\mathbf{v}_k$ still spans $H$; (b) if $H \ne \{\mathbf{0}\}$, some subset of $S$ is a basis for $H$.

THEOREM 6 (Page 20): The pivot columns of $A$ form a basis for $\text{Col } A$. (Warning: use pivot columns of the original matrix $A$, not its echelon form $B$, because row operations can alter column space.)

§ 4.4 Coordinate Systems (座標系統)

Pages 1 - 24

THEOREM 7 — Unique Representation Theorem (Page 1): If $\mathcal{B} = \{\mathbf{b}_1, \dots, \mathbf{b}_n\}$ is a basis for $V$, then each $\mathbf{x} \in V$ can be written uniquely as $\mathbf{x} = c_1\mathbf{b}_1 + \dots + c_n\mathbf{b}_n$.

DEFINITION (Page 3): The weights $c_1, \dots, c_n$ are the $\mathcal{B}$-coordinates of $\mathbf{x}$, and $[\mathbf{x}]_{\mathcal{B}} = \begin{bmatrix} c_1 \\ \vdots \\ c_n \end{bmatrix} \in \mathbb{R}^n$ is the $\mathcal{B}$-coordinate vector of $\mathbf{x}$. The map $\mathbf{x} \mapsto [\mathbf{x}]_{\mathcal{B}}$ is the coordinate mapping.

Change-of-Coordinates in $\mathbb{R}^n$ (Pages 13 - 14): For $P_{\mathcal{B}} = [\mathbf{b}_1 \;\; \dots \;\; \mathbf{b}_n]$, $\mathbf{x} = P_{\mathcal{B}}[\mathbf{x}]_{\mathcal{B}}$ and $[\mathbf{x}]_{\mathcal{B}} = P_{\mathcal{B}}^{-1}\mathbf{x}$.

THEOREM 8 & Isomorphism (Pages 16 - 20): $\mathbf{x} \mapsto [\mathbf{x}]_{\mathcal{B}}$ is a one-to-one linear transformation from $V$ onto $\mathbb{R}^n$ (an isomorphism, preserving linear combinations: $[c_1\mathbf{u}_1 + \dots + c_p\mathbf{u}_p]_{\mathcal{B}} = c_1[\mathbf{u}_1]_{\mathcal{B}} + \dots + c_p[\mathbf{u}_p]_{\mathcal{B}}$). In Example 5, with $\mathcal{B} = \{1, t, t^2, t^3\}$, $\mathbb{P}_3$ is isomorphic to $\mathbb{R}^4$.

§ 4.5 The Dimension of a Vector Space (向量空間的維度)

Pages 1 - 15

THEOREM 9 (Page 2): If $V$ has a basis of $n$ vectors, any set in $V$ with more than $n$ vectors is linearly dependent.

THEOREM 10 (Page 4): If $V$ has a basis of $n$ vectors, every basis of $V$ has $n$ vectors.

Dimension Definition (Page 5): If $V$ is spanned by a finite set, $\dim V$ is the number of vectors in a basis for $V$; $\dim \{\mathbf{0}\} = 0$. Otherwise $V$ is infinite-dimensional ($\dim \mathbb{R}^n = n$, $\dim \mathbb{P}_n = n+1$, $\mathbb{P}$ is infinite-dimensional).

THEOREM 11 (Page 10): Any linearly independent set in a subspace $H$ of finite-dimensional $V$ can be expanded to a basis for $H$, and $\dim H \le \dim V$.

THEOREM 12 — Basis Theorem (Page 12): For $p$-dimensional $V$ ($p \ge 1$), any linearly independent set of $p$ vectors in $V$ is a basis for $V$, and any spanning set of $p$ vectors in $V$ is a basis for $V$.

Dimensions of $\text{Nul } A$ and $\text{Col } A$ (Pages 13 - 15): $\dim \text{Nul } A =$ number of free variables in $A\mathbf{x} = \mathbf{0}$; $\dim \text{Col } A =$ number of pivot columns in $A$.

§ 4.6 Rank (秩)

Pages 1 - 22

Row Space & THEOREM 13 (Pages 2 - 5): For an $m \times n$ matrix $A$, $\text{Row } A$ (subspace of $\mathbb{R}^n$, equal to $\text{Col } A^T$) is spanned by the rows of $A$. Row-equivalent matrices have the same row space; if $B$ is in echelon form, the nonzero rows of $B$ form a basis for $\text{Row } A$.

DEFINITION & THEOREM 14 — Rank Theorem (Pages 13 - 14): $\text{rank } A = \dim \text{Col } A$. For an $m \times n$ matrix $A$, $\dim \text{Col } A = \dim \text{Row } A = \text{rank } A =$ number of pivot positions in $A$, and:

$\text{rank } A + \dim \text{Nul } A = n$

Invertible Matrix Theorem (Continued, Pages 20 - 22): For an $n \times n$ matrix $A$, invertibility is equivalent to: (m) columns of $A$ form a basis of $\mathbb{R}^n$; (n) $\text{Col } A = \mathbb{R}^n$; (o) $\dim \text{Col } A = n$; (p) $\text{rank } A = n$; (q) $\text{Nul } A = \{\mathbf{0}\}$; (r) $\dim \text{Nul } A = 0$.

§ 4.7 Change of Basis (基底變換)

Pages 1 - 14

THEOREM 15 (Page 5): Let $\mathcal{B} = \{\mathbf{b}_1, \dots, \mathbf{b}_n\}$ and $\mathcal{C} = \{\mathbf{c}_1, \dots, \mathbf{c}_n\}$ be bases of $V$. There is a unique $n \times n$ change-of-coordinates matrix from $\mathcal{B}$ to $\mathcal{C}$, denoted $P_{\mathcal{C}\leftarrow\mathcal{B}}$, such that:

$[\mathbf{x}]_{\mathcal{C}} = P_{\mathcal{C}\leftarrow\mathcal{B}}[\mathbf{x}]_{\mathcal{B}}$

$P_{\mathcal{C}\leftarrow\mathcal{B}} = \big[\, [\mathbf{b}_1]_{\mathcal{C}} \;\; [\mathbf{b}_2]_{\mathcal{C}} \;\; \cdots \;\; [\mathbf{b}_n]_{\mathcal{C}} \,\big]$

Inverse & Standard Basis Relation (Pages 7 - 14): Since $P_{\mathcal{C}\leftarrow\mathcal{B}}$ is invertible, $(P_{\mathcal{C}\leftarrow\mathcal{B}})^{-1} = P_{\mathcal{B}\leftarrow\mathcal{C}}$. In $\mathbb{R}^n$, $[\mathbf{c}_1 \;\; \mathbf{c}_2 \;\; | \;\; \mathbf{b}_1 \;\; \mathbf{b}_2] \sim [I \;\; | \;\; P_{\mathcal{C}\leftarrow\mathcal{B}}]$, and $P_{\mathcal{C}\leftarrow\mathcal{B}} = P_{\mathcal{C}}^{-1} P_{\mathcal{B}}$.
